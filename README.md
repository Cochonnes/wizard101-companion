## Installation Linux

⚠️ I haven't really tested the Linux support yet.

- Download the main ZIP file from: https://codeload.github.com/Cochonnes/wizard101-companion/zip/refs/heads/main
  - Extract the ZIP (obviously)
- Install Python
  - Open the terminal and run "sudo apt install python3-venv"
  - This will install the Python 3 prequisite
- Run "install.sh" once
  - You can use the terminal "sh install.sh"
  - This will download the required features like OCR and stuff into the "venv" folder
- To start the app, run "sh start.sh" in the terminal
  - In order to use hotkeys with the game running, you have to start the app as sudo "sudo sh start.sh"

- Optional: Install Google Chrome browser to fetch new content

## Features
- More than 1850 bosses for easy look up of stats and cheats
  - OCR integration, so you no longer need to manually look up the bosses (granted OCR detects 'em)   
- Quest tracker
- On-Screen overlay
- Round tracker
  - For bosses that have cheats based on round count
- Strategy planer
  - For the really tough ones
- Easy linking of round trackers and guides to specific bosses
- Gear planner
  - Save the best loadouts for each level and school, viewable with just a click
- Deck builder
- Spell overview
- Easily share deck and gear setups  
- Damage calculator that takes your wizards stats, and the bosses ones into account
